# PROJECT ARIADNE

PROJECT ARIADNEは、Webアプリケーション開発における項目定義、データベース定義、API定義を一元的に管理するWindowsデスクトップアプリケーションです。

設計情報を相互に関連付けることで、設計の整合性を保ち、変更に伴う作業を支援します。

## Purpose

Webアプリケーション開発では、項目定義、データベース定義、API定義が個別に管理されることが多く、設計情報の重複や不整合、変更時の修正漏れが発生します。

PROJECT ARIADNEは、これらの設計情報を一元管理し、設計者が整合性を意識しながら設計を進められる環境を提供します。

## Vision

設計情報が相互につながり、変更が生じても一貫性を維持できる開発環境を目指します。

設計者が個々の定義の整合性確認や成果物の転記作業に追われることなく、設計そのものに集中できる世界を実現します。

## Overview

PROJECT ARIADNEは、以下の設計情報を管理します。

- **Elements**：アプリケーションで使用する項目の定義
- **Database**：テーブル、カラム、制約などのデータベース定義
- **API**：APIのインターフェース定義

これらの設計情報は、単一の`ariadne.yaml`を正本として管理します。

また、管理する設計情報をもとに、DDLやOpenAPI Specification（OAS）などの成果物を生成します。

アプリケーションはWindowsデスクトップ環境で動作し、設計情報の参照・編集をGUIから行えます。
